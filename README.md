# 클래스로(Classro) 회사 소개 웹사이트

동네 공방·작업실의 원데이 클래스(도자기, 베이킹, 가죽공예, 플라워, 드로잉, 향수)를 앱에서 찾고 바로 예약·결제하는 서비스 **클래스로**의 소개 사이트입니다.
`00_회사소개.md`를 기준으로 만들었습니다.

> 수업용 가상 회사입니다. 등장하는 회사·인물·수치는 모두 지어낸 것입니다.

## 폴더 구조

```
TEST/
├── index.html        # 페이지 본문
├── css/
│   └── style.css     # 스타일 (반응형, 청자색 기반 테마)
├── js/
│   └── main.js       # 모바일 메뉴, 아코디언, 스크롤 효과
├── 00_회사소개.md     # 사이트 내용의 기준 문서
└── README.md
```

## 실행 방법

별도 빌드 없이 `index.html`을 브라우저에서 열면 됩니다.

```bash
open index.html
```

| 숫자로 보기 | 제휴 공방 420곳, 월 예약 약 7,000건, 평균 결제액 42,000원, 지역·직군별 막대 그래프 |

## 디자인 메모

- 색은 공방 재료에서 가져왔습니다. 청자색이 기본이고 버터색, 라일락, 가죽색, 꽃분홍을 포인트로 씁니다.
- 375px 모바일 폭까지 대응하며, 좁은 화면에서는 메뉴가 접힙니다.
- 키보드 포커스 표시(`:focus-visible`), `prefers-reduced-motion` 존중, 터치 영역 44px 이상을 지킵니다.
